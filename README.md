# NPC Skins para Custom NPCs (Minecraft 1.7.10)

Repositorio oficial de skins en tiempo real para **Custom NPCs** con el mod **NPC Skins Sync** (`NPCSkins-1.7.10-1.0.jar`).

---

## 🎨 Cómo añadir una skin nueva
1. Sube cualquier archivo `.png` (ejemplo: `goku.png`, `guardia_real.png`, `vegeta.png`) directamente a la raíz de este repositorio.
2. Haz clic en **Commit changes**.
3. **¡Listo!** En el juego, todos los jugadores recibirán la skin automáticamente.

---

## 🎮 En el juego (Minecraft 1.7.10)
* **Abrir el Buscador de Skins:** Pulsa la tecla **`K`** o escribe el comando **`/skins`** en el chat.
* **Buscador integrado:** Escribe el nombre para filtrar entre todas las skins disponibles en tiempo real.
* **Copiar Nombre:** Selecciona una skin y dale a **Copiar Nombre** (se copia a tu portapapeles de Windows).
* **Ponerla en el NPC:** 
  * Haz clic derecho al NPC con la **Custom NPCs Wand**.
  * Ve a **Display** -> En **Texture / Player**, pega el nombre con `Ctrl + V`.
* **Sincronizar al instante:** Si acabas de subir una skin a GitHub, dale al botón **Sincronizar** dentro del menú o escribe `/skins sync`.

---

## ⚙️ Comandos del Mod
* `/skins` - Abre la ventana visual con el buscador.
* `/skins sync` - Descarga al instante cualquier skin nueva de GitHub sin reiniciar Minecraft.
* `/skins open` - Abre tu carpeta local donde se guardan las skins.
* `/skins list` - Muestra todas las skins disponibles en el chat.
