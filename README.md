# NPC Skins para Custom NPCs (Minecraft 1.7.10)

Repositorio oficial de skins en tiempo real para **Custom NPCs** con el mod **NPC Skins Sync** (`NPCSkins-1.7.10-1.0.jar`).

---

## 🚀 Novedad: ¡Sube skins directamente desde Minecraft!
Ya no hace falta entrar a la página web de GitHub para añadir skins nuevas. Cualquier persona con el mod puede subirlas directamente desde el juego:

1. Pulsa la tecla **`K`** (o escribe **`/skins`** en el chat).
2. Haz clic en el botón verde **`[ ⬆ Subir ]`**.
3. Se abrirá la ventana del explorador de Windows para que elijas la imagen desde tu ordenador (por ejemplo, desde tu carpeta de Descargas).
4. El mod **validará automáticamente** la imagen:
   * Solo admite archivos `.png`.
   * **Comprueba las dimensiones de Minecraft:** debe ser exactamente de **64x64** o **64x32** (o 128x128 HD).
   * Límite de tamaño: máximo 300 KB.
5. El mod la subirá a este repositorio de GitHub en 2 segundos y la guardará en la carpeta local de todos los jugadores.

---

## 🎮 En el juego (Minecraft 1.7.10)
* **Abrir el Buscador de Skins:** Pulsa la tecla **`K`** o escribe el comando **`/skins`** en el chat.
* **Buscador integrado:** Escribe el nombre en la barra de texto para filtrar las skins en tiempo real.
* **Copiar Nombre:** Selecciona una skin y dale a **`[ Copiar ]`** (se copia al portapapeles de Windows).
* **Ponerla en el NPC:** 
  * Haz clic derecho al NPC con la **Custom NPCs Wand**.
  * Ve a **Display** -> En **Texture / Player**, pega el nombre con `Ctrl + V`.
* **Sincronizar al instante:** Botón **`[ Sincronizar ]`** o comando `/skins sync`.
* **Abrir carpeta local:** Botón **`[ Abrir Carpeta ]`** o comando `/skins open`.

---

## ⚙️ Comandos del Mod
* `/skins` - Abre la ventana visual con el buscador y subidor.
* `/skins sync` - Descarga al instante cualquier skin nueva de GitHub sin reiniciar Minecraft.
* `/skins open` - Abre la carpeta local donde se guardan las skins.
* `/skins list` - Muestra todas las skins disponibles en el chat.
